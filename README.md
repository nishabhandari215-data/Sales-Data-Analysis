# Sales Data Analysis – Excel Dashboard

## Project Overview
This project analyzes sales data using Microsoft Excel to identify sales performance, profitability, product performance, regional trends, and customer segment performance.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Charts
- Slicers

## Analysis Performed
- Data Cleaning and Validation
- State-wise Sales Analysis
- State-wise Profit Analysis
- Product-wise Profit Analysis
- Customer Segment-wise Sales Analysis
- KPI Analysis
- Interactive Dashboard

## Key Business Insights
- Gujarat has the highest sales among the states.
- Gujarat has the highest profit among the states.
- Laptop generates the highest profit among the products.
- Small Business generates the highest sales among customer segments.

## Dashboard Features
The dashboard includes:
- Total Sales
- Total Cost
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin
- Interactive State, Product, and Customer Segment slicers
